# GBR Paints Pro - تصميم وبنية قاعدة البيانات (Database Design)

توثق هذه الصفحة البنية الهيكلية لقاعدة بيانات نظام **GBR Paints Pro** المعتمدة على محرك **Room Database / SQLite**. تمت تهيئة المخطط (Schema) لتسهيل العلاقات السريعة، الحفاظ على سلامة البيانات، ودعم الاستعلامات الفعالة للواجهة الرسومية والتقارير الرياضية.

---

## 1. مخطط الكيانات والعلاقات (Schema Mapping)

تم تصميم الجداول مع مراعاة العلاقات المنطقية (Relations) وفهرستها لضمان سرعة الاستعلام والبحث السريع عن البيانات حتى مع كبر حجم البيانات والملفات.

### أ) جدول المواد الخام (`raw_materials`)
يخزن مواصفات وتفاصيل المواد الخام الكيميائية والمذيبات المستخدمة في خلط وإنتاج الدهانات.

| اسم الحقل (Column Name) | النوع (Type) | الوصف (Description) |
| :--- | :--- | :--- |
| `id` (PK) | TEXT | المعرف الفريد للمادة الخام (UUID) |
| `name` | TEXT | اسم المادة الخام (مثال: ثاني أكسيد التيتانيوم) |
| `code` | TEXT | الكود الصناعي للمادة الخام لتسهيل البحث السريع |
| `category` | TEXT | فئة المادة (مذيبات، مواد مالئة، أصباغ، إضافات) |
| `currentStock` | DOUBLE | كمية المخزون الحالي بالكيلوجرام |
| `minimumLimit` | DOUBLE | حد إعادة الطلب الأدنى لتفادي نقص المواد |
| `costPerKg` | DOUBLE | التكلفة المالية للكيلوجرام الواحد بالعملة المحلية |
| `supplier` | TEXT | اسم المورد أو الشركة المصنعة |
| `createdAt` | LONG | طابع زمني لوقت إنشاء السجل |

---

### ب) جدول التركيبات الكيميائية (`formulations`)
يخزن بيانات المنتجات والخلطات الكيميائية وتكويناتها المعتمدة والمرحلية.

| اسم الحقل (Column Name) | النوع (Type) | الوصف (Description) |
| :--- | :--- | :--- |
| `id` (PK) | TEXT | المعرف الفريد للتركيبة |
| `code` | TEXT | كود المنتج الفريد (مثال: GBR-GLOSS-100) |
| `name` | TEXT | الاسم التجاري للمنتج أو الدهان |
| `version` | TEXT | رقم الإصدار الحالي للتركيبة (مثال: الإصدار 1) |
| `status` | TEXT | حالة التركيبة (🟢 معتمدة للإنتاج، 🟡 قيد التطوير، ⚪ مسودة) |
| `density` | DOUBLE | الكثافة النظرية المستهدفة للمنتج (g/cm³) |
| `solidsPercentage` | DOUBLE | نسبة المواد الصلبة النظرية في الخليط |
| `totalYieldKg` | DOUBLE | إجمالي وزن الباتش النموذجي للخلطة (مثال: 1000 كجم) |
| `notes` | TEXT | تعليمات التشغيل والملاحظات الفنية للمصنع |
| `lastUpdated` | LONG | تاريخ آخر تعديل على التركيبة |

---

### ج) جدول مراجعات وإصدارات التركيبات (`revisions`)
سجل تاريخي يوثق تاريخ التعديل على التركيبات وأسباب التغيير ونسب المكونات القديمة.

| اسم الحقل (Column Name) | النوع (Type) | الوصف (Description) |
| :--- | :--- | :--- |
| `id` (PK) | TEXT | المعرف الفريد للمراجعة |
| `formulationId` | TEXT | المعرف الفريد للتركيبة المرتبطة |
| `versionName` | TEXT | اسم الإصدار للنسخة المؤرشفة |
| `changeLog` | TEXT | تفاصيل التعديل والتحسينات المضافة بالخلطة |
| `componentsJson` | TEXT | هيكل JSON يضم المواد ونسبها السابقة للتوثيق الكامل |
| `createdDate` | LONG | تاريخ ووقت تسجيل المراجعة |

---

### د) جدول أوامر الإنتاج (`production_orders`)
يخزن تفاصيل أوامر الإنتاج وتشغيل الباتشات في صالة الخلط والتعبئة.

| اسم الحقل (Column Name) | النوع (Type) | الوصف (Description) |
| :--- | :--- | :--- |
| `id` (PK) | TEXT | المعرف الفريد لأمر الإنتاج |
| `orderNumber` | TEXT | الرقم التسلسلي لأمر التشغيل (تلقائي) |
| `formulationId` | TEXT | معرّف التركيبة الكيميائية المستخدمة |
| `targetBatchWeight` | DOUBLE | الوزن المستهدف للباتش بالكامل بالكيلوجرام |
| `status` | TEXT | حالة الأمر (مخطط، قيد التشغيل، مكتمل، ملغى) |
| `plannedDate` | LONG | التاريخ المخطط لبدء الإنتاج |
| `completedDate` | LONG | تاريخ إتمام الباتش وتسجيله بالكامل |
| `actualYield` | DOUBLE | الناتج الفعلي المستخرج والموزون بالخلاط |
| `packagingSelected` | TEXT | نوع العبوات المستخدمة للتعبئة من الإعدادات |
| `totalPackages` | INTEGER | عدد العبوات المعبأة والجاهزة للشحن |

---

### هـ) جدول جلسات فحص المختبر (`laboratory_sessions`)
سجلات فحوصات الجودة والمعايرة والتحليلات المعملية لكل باتش أو أمر إنتاج.

| اسم الحقل (Column Name) | النوع (Type) | الوصف (Description) |
| :--- | :--- | :--- |
| `id` (PK) | TEXT | المعرف الفريد لجلسة المختبر |
| `orderId` | TEXT | معرّف أمر الإنتاج المرتبط بالجلسة |
| `testerName` | TEXT | اسم فني الجودة أو الكيميائي المسؤول عن الفحص |
| `status` | TEXT | حالة الجلسة (ناجح ومطابق 🟢، قيد الفحص 🟡، مرفوض ومخالف 🔴) |
| `laboratoryNotes` | TEXT | التوصيات المعملية ومبررات القبول أو الرفض |
| `createdAt` | LONG | تاريخ تسجيل الجلسة بالمختبر |

---

### و) جدول اختبارات الجودة الفردية (`laboratory_tests`)
يخزن نتائج الاختبارات الفيزيائية والكيميائية الدقيقة داخل الجلسة المعملية.

| اسم الحقل (Column Name) | النوع (Type) | الوصف (Description) |
| :--- | :--- | :--- |
| `id` (PK) | TEXT | المعرف الفريد للاختبار |
| `sessionId` | TEXT | معرّف الجلسة المعملية التابع لها |
| `testType` | TEXT | نوع الاختبار (اللزوجة القياسي، اللزوجة المخفف، الكثافة، الصلابة) |
| `spindle` | TEXT | رقم المغزل المستخدم في الفحص (NDJ-8S) |
| `speed` | TEXT | سرعة الدوران المحددة للجهاز (RPM) |
| `measuredValue` | DOUBLE | القيمة المقاسة الفعلية للمتغير الفيزيائي |
| `status` | TEXT | نتيجة الاختبار الفردي (مطابق، غير مطابق) |
| `createdAt` | LONG | تاريخ تسجيل قراءة الاختبار الفردي |

### ز) جدول ملحقات ووثائق المختبر (`laboratory_attachments`)

| اسم الحقل (Column Name) | النوع (Type) | الوصف (Description) |
| :--- | :--- | :--- |
| `id` (PK) | TEXT | المعرف الفريد للمرفق |
| `sessionId` | TEXT | معرّف جلسة المختبر المرتبط بها المرفق |
| `testName` | TEXT | الوصف أو العنوان الخاص بالصورة المرفقة |
| `filePathOrUrl` | TEXT | المسار المحلي للصورة بالهاتف أو رابط التخزين |
| `createdAt` | LONG | تاريخ ووقت التقاط أو رفع الصورة |

---

### ح) جدول التنبيهات التشغيلية (`operational_alerts`)
لتوليد وإشعاع التنبيهات الذكية المرتبطة بتشغيل الآلات، الأقسام، أو شذوذ النتائج الفيزيائية.

| اسم الحقل (Column Name) | النوع (Type) | الوصف (Description) |
| :--- | :--- | :--- |
| `id` (PK) | TEXT | المعرف الفريد للتنبيه |
| `title` | TEXT | عنوان التنبيه أو التحذير |
| `description` | TEXT | تفاصيل التنبيه الفنية والإجراء الموصى باتباعه |
| `mainSection` | TEXT | القسم المرتبط (المختبر، الإنتاج، المستودع، عام) |
| `bindingScope` | TEXT | نطاق الارتباط (ALL، ELEMENT_SPECIFIC) |
| `bindingElementName` | TEXT | اسم الكيان المرتبط بالتنبيه للتوجيه المباشر له |
| `alertLevel` | TEXT | مستوى الخطورة (INFO, WARNING, CRITICAL, EMERGENCY) |
| `status` | TEXT | حالة التنبيه النشطة (ACTIVE, SOLVED, ARCHIVED) |
| `createdAt` | LONG | تاريخ تسجيل وإطلاق التنبيه التشغيلي |

## 2. آليات حماية وتكامل قاعدة البيانات (DB Integrity)
* **الفهارس (Indices)**: يتم إنشاء فهارس فريدة على الأعمدة الأكثر بحثاً مثل `code` في جدول التركيبات، و`orderNumber` في جدول الإنتاج، و`sessionId` في جداول المختبر لتسريع عمليات البحث الكبيرة.
* **العمليات المتزامنة (Transaction Threading)**: تتم كافة عمليات الكتابة في قاعدة البيانات بالاعتماد على مكوّنات Kotlin Coroutines و Dispatchers.IO لتجنب تجميد واجهة المستخدم (UI Freeze).
* **إصلاح قاعدة البيانات وتجاوز الأخطاء (Schema Self-Healing)**: يحتوي التطبيق على آلية ذكية لإعادة بناء الجداول وفحص سلامة هياكل SQLite (Rebuild Schemas) من داخل شاشة الإعدادات لمعالجة أي شذوذ في قواعد البيانات المحدثة محلياً.
